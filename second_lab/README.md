# Лабораторная работа №2  
## Построение СКНФ и СДНФ на основании таблиц истинности

## Описание работы

В рамках данной лабораторной работы реализована программа для анализа логических функций булевой алгебры.  
Программа принимает на вход логическое выражение в свободной форме, строит для него таблицу истинности и выполняет полный набор операций, связанных с представлением, анализом и минимизацией булевых функций.

Основная цель работы — изучить способы представления логических функций, научиться строить совершенные нормальные формы, определять свойства функций, выполнять булеву дифференциацию и минимизацию различными методами.

---

## Цель лабораторной работы

Освоить методы анализа булевых функций и реализовать программу, которая позволяет:

- строить таблицу истинности по введённой логической формуле;
- формировать СДНФ и СКНФ;
- получать числовую и индексную формы функции;
- определять принадлежность функции к классам Поста;
- строить полином Жегалкина;
- находить фиктивные переменные;
- вычислять булевы производные;
- минимизировать функцию различными методами.

---

## Постановка задачи

Необходимо разработать программу, которая принимает логическую функцию, содержащую операции:

- `!` — отрицание;
- `&` — конъюнкция;
- `|` — дизъюнкция;
- `->` — импликация;
- `~` — эквивалентность.

Функция может содержать до пяти переменных:

- `a`
- `b`
- `c`
- `d`
- `e`

На основании введённой функции программа должна:

1. Построить таблицу истинности.
2. Построить СДНФ и СКНФ.
3. Вывести числовую форму СДНФ и СКНФ.
4. Вывести индексную форму функции.
5. Определить принадлежность функции к классам Поста.
6. Построить полином Жегалкина.
7. Найти фиктивные переменные.
8. Выполнить булеву дифференциацию:
   - частные производные;
   - смешанные производные.
9. Выполнить минимизацию функции:
   - расчётным методом;
   - расчётно-табличным методом;
   - табличным методом (карта Карно).
