# Лабораторная работа №4  
## Реализация хеш-таблицы

## 1. Тема работы

Тема лабораторной работы — реализация структуры данных **хеш-таблица**.

Хеш-таблица — это структура данных, которая хранит пары вида:

```text
ключ -> значение
```

и позволяет быстро выполнять основные операции:

```text
добавление, поиск, изменение и удаление данных
```

В данной лабораторной работе реализована собственная хеш-таблица без использования встроенного словаря Python `dict` как основной структуры хранения.

---

## 2. Вариант задания

Вариант: **1**

Метод разрешения коллизий:

```text
разрешение коллизий с помощью цепочек: связный список
```

Это означает, что если несколько разных ключей получают один и тот же хеш-адрес, они сохраняются в одной ячейке таблицы в виде цепочки.

Пример:

```text
15: [key=ab, value=first] -> [key=ba, value=second]
```

В этом примере оба ключа попали в ячейку с индексом `15`, поэтому в этой ячейке была создана цепочка связного списка.

## 7. Принцип работы хеш-таблицы

Хеш-таблица работает по следующему принципу.

Пользователь вводит ключ и значение:

```text
key = ab
value = first
```

Сначала ключ преобразуется в числовое значение `V`.

В данной программе используется простой способ вычисления `V`:

```python
V = sum(ord(char) for char in key)
```

То есть числовое значение ключа равно сумме кодов всех символов ключа.

Для ключа `ab`:

```text
ord('a') = 97
ord('b') = 98

V = 97 + 98 = 195
```

После этого вычисляется хеш-адрес:

```text
h = V % H
```

где:

```text
H — размер хеш-таблицы;
h — индекс ячейки.
```

Если размер таблицы равен `20`, то:

```text
h = 195 % 20 = 15
```

Значит, запись будет помещена в ячейку с индексом `15`.

## 8. Хеш-функция

В работе используется принцип хеш-функции из методических материалов:

```text
h = V mod H
```

где:

```text
V — числовое значение ключа;
H — размер хеш-таблицы;
h — хеш-адрес.
```

В программе это реализовано следующим образом:

```python
def calculate_V(key: str) -> int:
    if not key:
        raise ValueError("Ключ не может быть пустым")

    return sum(ord(char) for char in key)


def calculate_hash(key: str, table_size: int) -> int:
    if table_size <= 0:
        raise ValueError("Размер таблицы должен быть больше 0")

    v = calculate_V(key)
    return v % table_size
```

Дополнительно проверяется:

```text
1. ключ не должен быть пустым;
2. размер таблицы должен быть больше нуля.
```

## 9. Коллизии

Коллизия — это ситуация, когда разные ключи получают один и тот же хеш-адрес.

Например:

```text
ab -> V = 195 -> h = 15
ba -> V = 195 -> h = 15
```

Ключи разные, но сумма кодов символов одинаковая:

```text
ab = 97 + 98 = 195
ba = 98 + 97 = 195
```

Значит, оба ключа должны попасть в одну и ту же ячейку таблицы.

---

## 10. Разрешение коллизий

В соответствии с вариантом 1 используется метод цепочек.

Алгоритм добавления записи:

```text
1. Вычислить V.
2. Вычислить h.
3. Проверить ячейку table[h].
4. Если ячейка пустая — записать элемент туда.
5. Если ячейка занята — возникла коллизия.
6. При коллизии пройти по цепочке до конца.
7. Добавить новый элемент в конец связного списка.
```

Пример результата:

```text
15: [key=ab, value=first, V=195, h=15] -> [key=ba, value=second, V=195, h=15]
```

Таким образом, данные не теряются и не перезаписываются.

## 11. CRUD-операции

В программе реализованы основные CRUD-операции.

CRUD означает:

```text
Create — создание;
Read   — чтение;
Update — обновление;
Delete — удаление.
```

### Create

Добавление новой записи.

Пользователь вводит ключ и значение.

Если ключа ещё нет в таблице, запись добавляется.

Если ячейка свободна, запись помещается сразу в неё.

Если ячейка занята, возникает коллизия, и запись добавляется в цепочку.

Если ключ уже существует, повторная запись не добавляется.

### Read

Поиск записи по ключу.

Программа:

```text
1. вычисляет хеш-адрес ключа;
2. переходит в нужную ячейку;
3. просматривает цепочку;
4. если ключ найден — возвращает значение;
5. если ключ не найден — сообщает, что записи нет.
```

### Update

Обновление записи.

Программа ищет запись по ключу.

Если запись найдена, её значение заменяется новым.

Если ключ отсутствует, программа выводит сообщение:

```text
Запись не найдена.
```

### Delete

Удаление записи.

Программа ищет запись по ключу.

Если запись найдена, она удаляется.

Удаление работает в двух случаях:

```text
1. удаляется первый элемент в ячейке;
2. удаляется элемент внутри цепочки.
```

Если удаляется первый элемент цепочки, началом цепочки становится следующий элемент.

Если удаляется элемент внутри цепочки, предыдущий элемент начинает ссылаться на следующий.

## 12. Коэффициент заполнения

Коэффициент заполнения показывает, насколько таблица заполнена.

Формула:

```text
load_factor = count / size
```

где:

```text
count — количество записей в таблице;
size  — размер таблицы.
```

Например:

```text
count = 2
size = 20

load_factor = 2 / 20 = 0.10
```

В программе коэффициент выводится с двумя знаками после запятой.

В программе реализовано случайное добавление записей.

Пользователь выбирает:

```text

```

После этого вводит количество записей.

Генерация создаёт пары ключей, которые специально могут вызывать коллизии.

Это удобно для демонстрации работы метода цепочек.

## 19. Особенности реализации

Главная особенность реализации — собственная обработка коллизий.

Встроенный словарь Python `dict` не используется как основа хранилища.

Вместо этого создаётся список фиксированного размера:

```python
self.table: list[HashNode | None] = [None] * size
```

Каждая ячейка может быть:

```text
1. пустой;
2. содержащей один элемент;
3. содержащей цепочку из нескольких элементов.
```

Цепочка строится с помощью поля:

```python
next
```

у класса `HashNode`.
